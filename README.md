# nav_ia — presentación visual

Web estática de presentación del MCP nav_ia y de un caso CAD documentado.

Dirección prevista de GitHub Pages: https://felipe-klz.github.io/nav-ia-web/

Incluye14imágenes CAD, un esquema paramétrico ilustrativo y aplicaciones propuestas en seis industrias. No ejecuta el MCP ni recalcula el CAD.

Este repositorio contiene exclusivamente la presentación web y sus imágenes. No incluye archivos CAD, planos, BOM, informes completos de ingeniería, cálculos ni el código del servidor MCP.

El banco mostrado es un prototipo no liberado para fabricar ni utilizar; la página conserva los límites de las comprobaciones. El brief descargable se genera localmente, sin enviar datos.

Publicación: rama main, carpeta raíz, sin compilación. Fuentes de capacidades y capturas en assets/producto-fuentes.json y assets/procedencia.json.
